## 🚀 Recent Updates & Features
* **Direct Web3Forms Integration:** Users can now submit new supplier reports securely and directly through the website via the new `/submit` directory, bypassing the need to use WhatsApp for every report.
* **Sticky Call-to-Action Bar:** Added a persistent bottom navigation bar to make the reporting tool instantly accessible, especially for mobile users.
* **Optimized UI/UX:** Built with staggered list-loading animations, search filtering, and a synchronized Dark/Light mode toggle that works seamlessly across all pages.

## ⚠️ Disclaimer
